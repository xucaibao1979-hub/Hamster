# 功能说明

## 仪表盘与台账

仪表盘展示设备数量、异常和报废数量、未使用数量、资产购入原值，以及按年和分类统计的趋势。总价值默认是购入原值，并非折旧后的净值。

台账默认展示全部资产，每页 10 条；可切换固定资产、易耗品、软件资产，设置分页数量，使用搜索和筛选条件定位资产。资产详情包含编号、序列号、归属、分类、类型、状态、领用人、领用日期、购入日期、价格、描述与备注。台账列与详情编辑字段可配置；资产字典可维护分类、归属、类型、状态及自定义字段。

CSV 导入先预检查编号重复、格式与日期等问题，再由管理员确认写入。支持台账导出和资产标签。

## 流转与盘点

员工通过 IT小爱以资产编号或序列号精确查询已有资产。未使用、空闲或闲置且无人领用、无待处理申请时可发起领用。提交申请不会立即修改资产；管理员批准后才写入领用人、北京时间当天的领用日期和使用中状态。旧台账将“未使用”“闲置”填入领用人字段时，在没有绑定员工 ID 的条件下按占位值处理；真实领用人和已绑定员工仍阻止重复领用。

归还由管理员验收，转让由接收人确认后再由管理员批准。资产详情保留生命周期历史和字段前后快照；普通操作日志可单独清理。盘点任务可按编号或序列号确认资产，记录盘点人、时间与结果。

## 设置与数据保护

管理员可管理账号、密码、字典、统计口径、IT小爱审批授权、备份及操作记录。SQLite 数据位于持久化数据卷；自动备份每日执行，业务备份可下载和验证。业务 JSON 备份不包含账号密码、服务凭证等完整系统配置，灾难恢复应同时备份整个数据卷及单独保管的 `.env`。

系统适合中小规模内网使用；当前资产状态主体保存在 SQLite 中的单份状态文档，代码限制最多 10,000 条资产。更大规模部署需评估数据库拆分、分页与并发性能。
